# Occulto 

### A web app which encrypt any text or number using ceasers ciphers & morse code.

### Modes of Encryption 🔒 
* Caesars Cipher.  A  ->  C

### Tech Stack 🧑🏻‍💻
Frontend: **React, Typescript, Vite**
Store: **Zustand**

### Encryption Mode 🫆
* Caesars Cipher
  - Cipher plain text, implment custom shift of alphabets.
